## 1. 项目概览

一个把本机 **Wallpaper Engine** 搬进 DSH Web 界面的插件：场景壁纸由内置的 MIT 开源引擎 **WebWallGL** 实时 WebGL 渲染（粒子 / puppet 骨骼 / SceneScript / 音频反应 / 鼠标交互），失败自动降级内嵌 MP4 与场景静态帧；Web 壁纸严格沙箱 + WE API；配 iOS 风液态玻璃 UI、遮挡暂停省电、ffmpeg 帧率上限转码、系统音频频谱与 Now Playing、自定义上传与自动轮播；设置存宿主端，**对 agent 零 token 开销**。Windows / macOS / Linux 三平台同一个包。

与本插件的共同基因：都是 DSH 双端插件（host Cordis 插件 + browser 客户端插件），都走 `dsh.client` 清单与 `window.__ModuleLoader__` 协议，都把配置存 host 侧（`settings.yaml` / 它的 `config.json`），都用 RPC-over-HTTP 通道 + revision 资产路由。**它是壁纸插件的"完全体"，本插件是桌宠插件的"轻量级"**——规模差约 50 倍（它的 `src/client.js` 单文件 328KB，测试 46+ 个），但底层协议完全一致，所以它的工程决策对本插件是直接可迁移的。

## 2. 架构剖析

### 2.1 双轴落点，不是"lib=服务端 / src=客户端"

它的 CODE-STRUCTURE 把落点决策写成两个正交属性：**跑在哪个进程**（浏览器 → `src/`） × **是否随包发布**（在 `package.json` 的 `files` 里 → `lib/`）。四格：

| | 发布 | 不发布 |
|---|---|---|
| **浏览器** | `lib/client.js`（全仓唯一生成物） | `src/**`（浏览器侧唯一真源） |
| **宿主** | `lib/index.js` + `lib/**` | `test/` · `scripts/` · `docs/` |

新文件落点是一棵六句决策树（要在浏览器跑吗 → 两侧共用吗 → 宿主实现吗 → 第三方副本吗 → 开发面吗 → 设计源资产吗），第一句命中就停。**两侧共用的唯一合法形态是"放 lib/ 且登记进内联清单"**，共享内核白名单只有一项（settings-schema），加第二个要显式登记——防止"顺手拆的工具函数"把边界泡软。

### 2.2 浏览器半边的组织：构建期内联，不用运行时模块

关键约束（ADR-0003）：ModuleLoader 的 `require` **只解析外部包**（react 等），不解析本地相对路径——运行时 `import './panel-tabs.js'` 根本不成立。它的解法是**构建期内联**：`scripts/build-client.mjs` 按一张显式清单（`INLINE_MODULES`，每项带 `why` 与 `markers`）把 `src/**` 剥掉 `export` 后按序注入同一个工厂作用域，运行时就是同作用域的普通声明，互相按名字引用。

配套的硬约束（构建期逐条断言）：内联模块必须浏览器安全（无 import/require/process/__dirname，且**先剥注释再判**）；不得有顶层语句读宿主状态（会 TDZ）；名字必须唯一；清单外的新文件**不会报错**，只是永远不进产物（它真踩过这个坑，此后补了"无孤儿"守卫）；产物曾入库（ADR-0003 D6）后改为**出库**（ADR-0012），三条路径各自现场构建。

> 与本插件的对照：我用 **esbuild bundle** 达到同样目的（本地相对引用在构建期消解，产物也是单文件 CJS + ModuleLoader 包裹）。两条路线解决同一个问题；它的理由是"可读性 + 零打包器依赖 + 显式清单"，esbuild 的理由是"生态标准 + 类型擦除 + CSS Modules 内联"。**可借鉴的是它的构建期断言文化**，不是它的内联机制——我在 v0.2.0 落地了对应的"构建新鲜度"守卫（见 §6）。

### 2.3 宿主半边的组织：门面 + 语义模块 + 路由表

`lib/index.js`（81KB）是门面：只做注册与协议聚合，不装新逻辑。真正干活的拆成语义模块：`steam-discovery`（Steam 定位）、`wallpaper-scan`（库扫描）、`transcode`（ffmpeg）、`scene-manifest/scene-probe`、`media-origin`（媒体源）、`serve`、`inventory`、`cache-prune`、`upload-store`、`settings-schema`（共享内核）……`lib/routes/` 下 20 个路由模块。**宿主与浏览器两半的唯一接口是 HTTP 路由表**——因此路由表是生成物（`docs/ROUTE-INDEX.md`），"手写必烂"。

它与本插件 host 半的组织方式同构（我的 `src/index.ts` 一个文件承载门面 + RPC + 扫描 + 资产路由，规模小所以没拆；它的规模下拆分是必然）。

### 2.4 宿主适配：三档事实来源 + 优先级裁决

`src/adapter.js` 示范了它的接口纪律：三档宿主（原生浏览器 / 非官方桌面端 / 官方桌面端）的判定事实来源是**请求头与 UA**（`x-dsh-desktop-renderer` 能力头、`Electron/` UA），宿主按请求观测并**闩锁**（只增不减），经 `GET /settings` 上报；页面侧在拿到上报前用本地信号给临时判定。优先级唯一裁决点：**手选 > 宿主上报 > 本地判定**。文件头把契约写成三段式：需要的外界 / 对外提供 / 异常一律吞掉退最保守档。这种"契约注释 + 保守退化"的写法遍布全仓。

## 3. 技术选型分析（逐项）

| 选型 | 它的做法 | 理由（它的声明） | 对本插件的可迁移性 |
|---|---|---|---|
| **纯 JS，无 TypeScript** | `src/` `lib/` 全 `.js`，tsc 只查 `lib/types/*.d.ts` | 浏览器安全约束（无 node API、构建期内联）下，TS 的编译期收益被"同作用域拍平"抵销大半；依赖图不可见本就只能用文档表达 | **部分可迁**：我的 TS 有 esbuild 擦除 + 真打包器，类型收益成立，保留。但它的"契约注释"纪律值得学 |
| **自研构建期内联 vs 打包器** | 40KB+ 的 build 脚本，含 markers/无孤儿/名字唯一断言 | 不引打包器；拆分显式登记；产物即契约 | **不迁机制，迁文化**：我加"构建新鲜度"守卫（§6） |
| **WebWallGL 实时渲染** | npm 依赖 `webwallgl@^3`，宿主从 node_modules 供给，包内只留适配页 | ADR-0001 三路线对比：离线静态帧（丢动画、复刻语义无底洞）、转码视频（同样丢交互）、依赖 WE 常驻（硬前置、跨平台不可行）。选定"内嵌实时渲染"，并配套**降级链**（实时→内嵌 MP4→实时抓帧→自定义→空态） | **不适用**（桌宠无此问题）；但它的"评估三条路线 + 写明重新考虑的触发线"的 ADR 写法是范本 |
| **x11 原生依赖** | `x11@^4` 用于 Linux 遮挡探测 | 遮挡暂停要跨平台 | 不适用 |
| **设置单一真源** | `lib/settings-schema.js` 一个文件定义键/默认值/范围/枚举，宿主 import + 构建期内联进浏览器，两侧 sanitize 从它派生 | ADR-0002：两份白名单各抄一份 → 漏键被静默丢弃 → "改了不生效"无日志无异常。真实事故驱动 | **✅ 已落地**（§6.1）：我的 `src/shared/settings-contract.ts` |
| **产物出库 + prepack** | `lib/client.js` 不入库；npm/Release tgz 由 `prepack` 现场构建；`github:` 直装明确不支持 | ADR-0012：pnpm 11 的 allowBuilds 闸让 git 直装的 `prepare` 被拒（issue #141）；产物入库让 clone 越来越胖 | **部分落地**：我保留 `prepare`（link:/本地安装需要），README 增加 pnpm≥10 的 allowBuilds 说明；zip/npm 分发走预构建产物 |
| **两级守卫** | 硬档（用户会撞上）跑 `npm run verify` 挡 PR；软档（仓库内务）跑 `verify:docs` 只出声 | ADR-0004：所有判据同一种红 → 改一行的合规成本被最贵的判据决定 → 贡献者绕过整条链 | **✅ 已落地**（§6.2） |
| **媒体中间件按需下载 + SHA-256 校验** | 运行时不强依赖，按需拉取并校验，不可用回退内置实现 | 包体积与平台多样性 | 不适用 |

## 4. 功能逻辑（挑与本插件相关的）

- **遮挡暂停**（它的招牌省电特性）：窗口被遮挡/最小化时暂停视频解码与场景实时渲染。注意它的精细区分——**窗口失焦暂停只在原生浏览器适配目标下提供**，桌面壳不失焦暂停（壳透明、壁纸仍可见，暂停会定格可见画面）。⇒ 我 v0.2.0 迁的是**页面可见性暂停**（`visibilitychange`），语义无歧义，见 §6.3。
- **出图降级链**：实时渲染 → 内嵌 MP4 → 实时抓帧 → 自定义画面 → 空态，配失败记忆与会话内重试。"渲染失败不许留黑屏"是 ADR-0001 的必要配套。⇒ 桌宠的对应物是**精灵图模式**：自定义皮肤导入失败/帧数不匹配时回退内置 SVG（我已天然具备，文档化了）。
- **自动轮播的"准备后切换"**：下一张准备完成才交接，失败候选自动跳过，过场可选（硬切/淡化/推移，系统"减少动态效果"时硬切）。⇒ 我 v0.2.0 做了简化版"心情预置"（一键快照，非轮播）；**皮肤轮换**列路线图。
- **预设全快照**（ADR-0011）：主题预设保存整套配置，可携带字体/吉祥物/头像资产，JSON 导出导入分享；套用前警示覆盖范围。⇒ 迁其"快照 = 完整补丁、原子落盘"的思想，见 §6.4。
- **宿主适配三档 + 能力矩阵**：客户端四处行为（外壳 CSS 门控、失焦暂停、媒体源说明）的唯一依据是 `adapterCaps()`。⇒ 桌宠不需要三档，但"一个能力矩阵函数做唯一依据"的模式我用于暂停/彩蛋开关的判断。
- **Now Playing / 系统音频频谱**：输出回环采集（不是麦克风），媒体中间件按需下载。⇒ 路线图：音频反应模式（打字节奏跟随系统音量）过于重型，不做；内置合成音已覆盖"声音"需求。

## 5. 工程文化（最值得学的部分）

1. **ADR 文化**：12 篇 ADR，每篇固定写 Context / Decision / Consequences（**收益与代价都写**）/ 重新考虑的触发线。它连"渲染器随包安装"都留了触发线（包体积成首要抱怨就改按需下载）。
2. **守卫分档 + 守卫审计工具**（ADR-0004/0007）：判据按"失败时用户会不会看到错的行为"分硬/软；`test/tools/` 下一堆 meta 工具（audit-guard-teeth 审守卫有没有牙、audit-import-closure 审发布闭包、token-contract 审主题令牌……）。**机器检查目标代码，不检查散文**。
3. **注释纪律**（ADR-0006）：涉及行数/体积这类会漂的量，写**复算命令**不写数字；模块头写"契约"（需要什么外界、对外提供什么）。
4. **文档即产品**：README.beginner（新手指南）、HOW-IT-WORKS（降级链唯一定义处）、TROUBLESHOOTING、UPGRADING、COEXISTENCE（多皮肤插件共存）、CONTRIBUTING（产物铁律）。默认值/范围**只指向 schema 文件**，文档不复述数值（D5）——"抄一份就是多一个无人复算的副本"。
5. **CHANGELOG 巨细**：docs/CHANGELOG.md 近 500KB，每次修复可溯源到 issue。

## 6. 对照本插件：借鉴决议与 v0.2.0 已落地清单

### 6.1 ✅ 设置单一真源契约（ADR-0002）——本次最大结构改进

- **问题**（它的原话也是我的病）：v0.1.0 的设置在三处各抄一份——host 的 `z.object` schema、host 的 `sanitizeConfig` 白名单、browser 的 `BongoCatSettings` 接口。白名单式漂移**静默**：任一侧漏一个键，那个键在经过那一侧时被丢弃，症状是"改了不生效"，无异常无日志。
- **落地**：新增 `src/shared/settings-contract.ts`——字段元数据（kind/default/min/max/writable）+ `SETTINGS_DEFAULTS` + `sanitizeSettingsPatch` + `WRITABLE_FIELDS`，**两侧派生**：host 的 schemastery schema 从契约默认值构建、config/set 用契约消毒器（未知字段/宿主权威字段/越界值一律大声拒绝）；browser 的 `BongoCatSettings` 类型从契约推导（`DefaultOf` 映射，不再手写接口）。
- **浏览器安全纪律**（它 ADR-0003 D1 的同款）：契约被 browser 半导入，因此**禁止 value import**——schemastery 的 schema 构建函数因此放在 host 侧 `src/index.ts`，契约只留纯数据 + 纯函数。
- **守卫对账**（它"机器检查目标代码"的同款）：host 冒烟测试每次运行断言「宿主 schema 键集 == 契约键集」且「默认值逐一深等」，外加消毒器 7 项单元断言。双端漂移从此**每次测试都红**。

### 6.2 ✅ 两级守卫验证 + CI（ADR-0004）

- `scripts/verify.mjs`：**硬档**（构建新鲜度——src 比 lib 新即红；契约探针构建；host/browser 冒烟共 65 项断言）非零退出，CI 挡 PR；**软档**（发布面 files[] 齐全、i18n 键"已声明/已使用/zh+en 完整"三查、CHANGELOG 覆盖当前版本）只出声不挡人。
- `.github/workflows/verify.yml`：push/PR 跑 `pnpm install → build → verify → lint`。
- 软档上线即立功：第一轮就抓到 CHANGELOG 缺 0.2.0 条目。

### 6.3 ✅ 可见性暂停（迁它的遮挡暂停，取无歧义子集）

`cat.ts` 监听 `visibilitychange`：隐藏 → 冻结全部 CSS 动画（`animation-play-state: paused`）、挂起 AudioContext、停跑休眠计时、忽略输入；恢复 → 重置空闲计时。它刻意**不迁**"窗口失焦暂停"——桌面壳里失焦不意味着不可见（它的 adapterCaps.blurPause 正是为此区分）；页面隐藏则无歧义。

### 6.4 ✅ 心情预置（迁 ADR-0011 预设全快照，简化版）

`presets.ts` 四个一键快照（专注/禅域/派对/夜猫）= 相关键的**完整补丁**，经**单个** config/set 原子落盘（host 消毒整块补丁，要么全落要么不落，没有半应用的心情）。它那版的资产携带/JSON 分享按桌宠尺度暂不需要，路线图见 §7。

### 6.5 ✅ 首启提示 + 工程件

- 首启 toast（它 notice.js 文化的迷你版）：一次性，状态入设置（`hintSeen`，契约新增字段）。
- `.editorconfig`、`eslint.config.mjs`（plain-JS 工具面：scripts/ 与 .verify/，TS 交给 tsc）、`prepack` 钩子、devDeps 补 eslint。
- README 增补 pnpm ≥10 的 allowBuilds 说明（它 issue #141 的同款坑：git 直装时 `prepare` 被闸）。

## 7. 路线图（评估过，暂不借）

| 候选 | 它的成本 | 不借/暂缓的理由 |
|---|---|---|
| WebGL 实时渲染 | 渲染器随包 + 降级链 + 抓帧校验 | 桌宠是 2D SVG + 精灵图，无此需求 |
| 液态玻璃 UI 改版 | 整套玻璃令牌 + 设置窗口重写 | 桌宠设置面板沿用 DSH 原生 section 即可，改版投入与"一只猫"不成比例 |
| 系统音频频谱 / Now Playing | 三平台媒体链路 + 中间件按需下载 | 桌面宠物不需要音频反应；合成音效已覆盖声音面 |
| 自动轮播（皮肤） | 准备后切换 + 失败跳过 + 过场 | **可做**：简化为"皮肤每 N 分钟轮换"一个配置项即可，排在 v0.3 候选 |
| 用户可存预设（JSON 导入导出） | 资产携带 + 覆盖确认 | 可做且轻：预设即补丁 JSON，v0.3 候选 |
| macOS/Linux Steam 扫描 | 三平台库发现 | 我的扫描已按平台优雅降级（非 Windows 只查 AppData/常见路径）；补 Linux `~/.steam` 解析是小改进 |
| ADR 目录 | 12 篇的维护成本 | 已有 ANALYSIS 文档承担"为什么"；后续重大决策直接落 `docs/adr/` |

## 8. 一页结论

`dsh-wallpaper-engine` 的真正价值不是"壁纸怎么搬"（那部分本插件用不上），而是它把**双端插件的工程约束**逼到了明面：浏览器半边没有模块解析器 ⇒ 构建期内联/打包；设置两侧共用 ⇒ 单一真源；判据有贵贱 ⇒ 两级守卫；产物与源码会漂 ⇒ 新鲜度守卫 + 产物出库；文档会腐化 ⇒ 数值只指向 schema、会漂的量写复算命令。v0.2.0 的 Bango Cat 插件把其中四条直接落地（契约、守卫、暂停、预置），测试从 50 项增至 65 项断言，其余按路线图排期。
